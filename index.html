01

Diagnóstico de un proceso

Para cuando algo te quita tiempo o se te escapa de las manos y no sabes por dónde empezar.

Te sirve si

Notas que pierdes tiempo o dinero en compras, citas, inventario o cobros, pero no sabes cuánto.

Incluye

  • • Una conversación de una hora

No incluye

Aplicar las mejoras, ni revisiones legales o fiscales.

02

Plataformas de datos a tu medida

Te sirve si

Incluye

  • • Estructura, fórmulas y avisos sencillos
